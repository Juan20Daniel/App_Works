# App Works
## Versión mínima 
ios: 15 para la librería google maps

## Configuración de variables de entorno
Renombrar archivo **.env.example** a **.env** y agregar llaves.

## Ejecución de la app
1. ejecutar `npm i` para instalar dependencias
2. ejecutar `npx pod-install ios`
3. correr la app con `npm run ios` o `npm run android`
